### The defect this task found

`resolvePublicBoard` split four trailing characters **before** looking for the
exact slug, so `/<owner>/board-under-test` resolved board `board-under` with
suffix `test` and answered `404`. Every server test had passed because their
fixtures happened to end in longer words; the browser journey with the shared
`BOARD_NAME` ("Board under test") failed on the first run. The resolver now tries
the exact slug, then the suffixed form, and the regression test pins it.

### What is deliberately not here

- **OG images.** The `<head>` carries `og:title`, `og:description` and `og:url`;
  there is no rasterised preview yet. D-50 names `resvg` for that and the
  dependency is not installed, so the image is absent rather than faked.
- **Reading a `link` board as a stranger.** The readable URL is served and not
  indexed, but an anonymous visitor has no actor until K3-02 issues link tokens
  and K3-03 signs the anonymous cookie. `/users/:username/boards/:segment/resolve`
  answer `404` for a credential-less caller today, which is the honest answer.
