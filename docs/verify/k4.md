**The filter, until the last handler landed.** `tools/list` served only the
tools whose handler existed, while `TOOL_NAMES` and the schemas stayed at 21.
Listing is a claim, and an agent that lists a tool and gets `-32603` from it
concludes the server is broken. With K4-05 landed the filter is a no-op and the
wire response is the frozen surface again; `test/mcp.test.ts` fails if that ever
stops being true in either direction.

## Notes for every row below

This workspace's Docker daemon publishes no reachable localhost port, so the
DB-backed commands ran in a container on the same network as Postgres:

```bash
docker run --rm --network klui-test-net -v "$PWD:/app" -w /app/server \
  -e DATABASE_URL=postgresql://klui:klui@klui-test-pg:5432/klui \
  node:26-bookworm sh -c "<command>"
```

The command quoted in each row is the `<command>`. `npx vitest run` on its own
is what `npm test -w server` runs.

alongside a write key. A key carries the role of the account that issued it, so
