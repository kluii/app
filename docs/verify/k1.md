## The authz matrix

```
 ✓ test/authz-matrix.test.ts (8 tests) 579ms
   ✓ asserts every cell, including every deny 576ms
```

The matrix enumerates visibility × link role × anonymous policy × member role ×
actor kind for every action, and fails when one `allow` is flipped. Every
permission decision in the process goes through `can()` in
`server/src/lib/authz.ts`; the ESLint gate forbids a second `owner_id`
comparison.

## Deviations, written down

1. **`recovery_code` added to the login body.** `docs/api.md` documented
   `{email_or_username, password, totp?}` and `docs/features/auth.md` §5
   requires recovery codes that work at login. The contract said nothing about
   how a recovery code is presented, so the field was added (optional, and
   mutually exclusive with `totp`), documented in `docs/api.md`, and covered by
   a test. Recorded here because a contract change is never silent.
2. **`/` answers `302`.** D-01 says `/` redirects to `/boards` or `/login`; the
   server decides from the credential it actually resolved, and the SPA keeps
   the same redirect for client-side navigation.
3. **The CSRF origin check compares against `KLUI_PUBLIC_URL`**, as
   `docs/security.md` §4 states. The Playwright server now sets that variable
   explicitly: inheriting a developer's `.env` made every browser write answer
   `403 forbidden_origin`, which reads as "accounts are broken".
4. **Two dependencies are declared but unused** — `otplib` (the TOTP
   implementation is 80 lines on `node:crypto`, tested against the RFC vectors)
   and `@fastify/swagger` (OpenAPI generation is a later wave). Removing
   `otplib` is queued with the wave-close dependency audit; leaving it declared
   while shipping hand-written code would be the worse half-measure.
5. **`POST /admin/users/:id/reset` returns the one-time link** to the admin, for
   out-of-band delivery. That is the documented path when SMTP is unset; the
   link is never logged.
