# ADR-0000 — Template

Copy this file to `NNNN-<slug>.md`, where `NNNN` is the next number and `<slug>` is the decision in three words. One decision per file. Never edit an accepted ADR: supersede it with a new one that says which it replaces.

## Status

`proposed` | `accepted` | `superseded by ADR-NNNN` | `rejected`

Date: YYYY-MM-DD. Deciders: who actually decided.

## Context

The situation, the constraint that forces a decision, and what breaks if nothing is decided. Facts, not preferences. If a number is involved, measure it and put the measurement here.

## Decision

One paragraph, present tense, active voice: "The move endpoint accepts neighbour ids." Not "we could consider".

## Consequences

What becomes easier, what becomes harder, what is now impossible. Include the cost: a file that must be touched every time, a class of bug that is now possible, a migration that must run.
